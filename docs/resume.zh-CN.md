# ClipRank 简历项目表述

## 建议名称

**ClipRank：基于视频多模态模型的 AIGC 短视频质量评估与候选排序**

**技术栈：** Python、PyTorch、Transformers、CUDA、bitsandbytes、OpenCV。

- 基于 VideoScore2 构建视频质量评估流程，结合视觉质量、文本匹配和物理/常识一致性评分，实现同提示词候选排序、异常结果校验及 HTML 人工复核报告。
- 在 RTX 4060 8 GB 上采用 NF4 双重量化、BF16、SDPA 和模型常驻批处理；设计帧采样与分辨率对照，在 20 段视频的固定评测子集上将 MAE 从 0.833 降至 0.650，并记录排序结果与统计不确定性。
- 基于 1,006 段视频建立评分头训练与评测流程，按提示词隔离 755/188/63 条训练、验证及测试样本；冻结多模态骨干，对比线性头、MLP 和带排序损失的 MLP，完成三随机种子共 9 次训练及独立测试对照。

## 面试时应补充的结果与边界

新评分头测试 MAE 0.691，原模型 0.683；候选对判对分别为 6/13 与 7/13，当前没有证据证明训练带来提升，应用默认评分器仍为原模型。20 段视频的输入配置实验与 63 段视频的评分头实验是不同子集，不应混在一起比较或推导提升。

冻结特征训练评分头，不等于对完整 VLM 做 LoRA/SFT。骨干原先已使用官方训练划分训练，验证隔离仅针对本项目评分头；不宣称骨干从未见过验证样本。项目未实现 DPO、GRPO、视频生成训练或商业部署。上游 VideoScore2 模型及数据归原作者，本项目成果是应用流程、输入对照、轻量训练与评测分析。
