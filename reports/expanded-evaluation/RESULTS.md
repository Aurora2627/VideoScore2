# ClipRank 扩大独立评测

先固定清单与方案，再对 20 段新视频、10 个新提示词进行 224/448 像素成对比较。模型、原始提示词、4 帧采样、4-bit NF4、种子、生成上限和选片权重固定。按提示词交替两种配置的执行顺序。

本轮没有训练、修改提示词、重新挑参数或自动修改默认配置。视频按元数据顺序选择，未按标注或预测筛选；所有失败、截断和并列结果均保留。

| 指标 | 224 像素 | 448 像素 |
|---|---:|---:|
| 有效视频数 / 计划数 | 20/20 | 20/20 |
| 平均绝对误差 MAE | 0.833 | 0.650 |
| 非平标注候选对方向正确数 | 4/9 | 5/9 |
| visual quality MAE | 0.800 | 0.500 |
| text-to-video alignment MAE | 0.900 | 0.700 |
| physical/common-sense consistency MAE | 0.800 | 0.750 |
| 平均生成秒数 | 108.771 | 113.368 |
| 峰值分配显存 GiB | 5.731 | 5.810 |

## 不确定性与参照

两种配置均有效的视频数：20/20；完整提示词组：10/10。
恒定输出 3 分参照的 MAE：0.750。这仅用于检查评分是否优于无区分能力的简单参照。
448 减 224 的按提示词平均 MAE 差：-0.183；提示词分组 bootstrap 95% 区间：[-0.467, 0.050]。负数表示 448 误差更低；区间跨 0 时，不支持稳定收益判断。

## 解释边界

仅 10 个提示词，相关性与区间均应作为小样本诊断。加权标注总分打平的组不计排序分母；模型预测打平不算方向正确。若存在无效输出，不能用有效样本上的 MAE 宣称完整评测提升，应同时检查 paired_* 和覆盖率。
元数据版本已固定；部分视频来自元数据指向的外部对象存储，URL 本身没有版本号，因此以下载记录中的 SHA256 标识实际字节。
原始模型输出、token、采样位置、输入形状、每视频耗时及显存、源代码快照、输入清单和执行记录均已保留。未来训练或调参需另划开发集与新检验集。
